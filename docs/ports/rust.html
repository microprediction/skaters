Rust

The portable Rust core, and the skaters-fast backend for Python.

cargo add skaters

A Rust implementation of the whole composition. Every forecaster is a struct with step(&mut self, y: f64) -> Vec<Dist>, and all state is serde-serializable data, so a skater checkpoints to JSON and restores. The mathematics gives identical bits on x86, ARM and WebAssembly, enforced by a cross-platform digest job in CI, and it steps laplace at about 14 microseconds per observation.

For Python users the same core is the opt-in skaters-fast backend, a PyO3 skin with the same interface at roughly 20 times the step rate. Install it with pip install "skaters[fast]" and import skaters_fast.
