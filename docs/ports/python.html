The reference implementation: pure standard library, no dependencies.

pip install skaters

The reference implementation. Pure standard library, no dependencies. The parity vectors are generated here, the benchmarks and papers run here, and features land here first. Every other port is checked against it to 1e-6.

The latest release on PyPI is 0.16.0. granger, flesaker and log_transform are on main and arrive in the next release; until then, pip install git+https://github.com/microprediction/skaters.
