JavaScript

Zero-dependency ES modules for the browser and Node.

npm install skaters

Zero-dependency ES modules covering the whole library. It runs in the browser and in Node; every live demo on this site is this build. Parity is enforced at more than 105,000 values on every test run, and every exported skater must round-trip through JSON and resume bit-exactly (stateToJSON, stateFromJSON).

In a page without a build step: import { laplace } from "https://cdn.jsdelivr.net/npm/skaters@0.16.0/index.mjs".
