torch (differentiable)

skaters on torch tensors, with gradients through every stage. Discuss.

pip install "skaters[torch]"

The library on torch tensors: transforms, leaves, ensembles, the lattice projection, the GPD tail splice, the parade, search, laplace and dantzig, in the same arithmetic order as the reference. The continuous hyperparameters are nn.Parameters reachable from laplace(k).parameters(), and gradients flow from a log score at the output through every stage.

It is held to the same parity vectors as the other ports at 1e-6, so a model initialised at the reference's values is laplace. This port is the substrate on which granger's parameters are trained. import skaters does not import torch. Its state is the canonical JSON layout (skaters.torch.state_to_json), so a checkpoint resumes in Python, Rust or JS. Not ported: the covariance estimators, mahalanobis and zbank.
