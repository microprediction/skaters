pak::pak("microprediction/skaters-r")

Pure R, covering the whole library including laplace, the adaptive search engine and the covariance estimators, at 105,798 parity values, with the adversarial gates, exact checkpoint-resume contracts and a clean R CMD check. The current version is 0.16.0.

It includes laplace and granger. A CRAN submission is planned once the surface and documentation settle.
