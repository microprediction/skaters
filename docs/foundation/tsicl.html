TS-ICL vs Laplace

EDF · TS-ICL tsicl-v1 Non-commercial zero-shot one-step change series

TS-ICL (EDF, June 2026) is an in-context forecaster trained to emit 99 quantile levels. Run zero-shot on CPU with a fixed 128-length context from the tsicl package at pinned weights revision 19c9403. Its public quantile-level check cannot represent some levels (0.07), so the adapter takes every trained level; its quantiles can cross, so they are sorted before scoring.

Resources: Model card

This page measures one thing: how sharp and how well calibrated TS-ICL's univariate predictive density is, one step ahead on a change series, scored against Laplace on identical windows. It leaves out the covariates, the multivariate inputs, the long horizons and the native quantile or path outputs the model was built for, and its log score passes through a reconstruction of the model's quantiles (the table note says which). A model can trail here and be the better tool for its own job.

Live snapshot  Derived from the week-long round-robin study; counts grow as coverage deepens. Everything scores against Laplace on the identical series and windows.

Standalone

The model's own predictive, run zero-shot, scored per series against Laplace. Win, draw and loss are decided one series at a time. Each series has a rolling test window of 64 one-step-ahead points, and both forecasters are scored on the same points. For each point take the difference of log predictive densities, dt = log pmodel(yt) − log pLaplace(yt), with each log density floored at −20 first. The series' mean d̄ is tested against zero by a Diebold–Mariano test: the standard error is Newey–West with a Bartlett kernel and lag round(n1/3). The model wins the series if d̄ > 1.96·SE, loses it if d̄ < −1.96·SE, and otherwise the series is a draw; a series with fewer than eight finite differences is a draw. A draw says the 64 points cannot separate the two forecasters at the 5% level. It does not say they are equal. With a window this short both win and loss counts understate the true rates, and the median ΔLL is the better measure of size. Counts are over the series both arms cover.

On the model's native 99 quantile levels

Arm TS-ICL(q99): the model's own 1% to 99% quantiles, every percentile, through the fixed-bandwidth reconstruction with no bandwidth inflation. The density beyond the 1% and 99% anchors is the Gaussian-mixture reconstruction's, not an output of the model. This is the fairest density the model can be given here, so it is the headline.

Tight nine-decile reconstruction

Arm TS-ICL: the same forecasts through quantile_dist, the reconstruction the original study used. Fed the exact deciles of a standard normal it covers 0.81, so a perfectly calibrated model reads 0.81 in this coverage column and pays for it in log score. It understates the model and is kept here for comparison with the earlier numbers.

Star plot

TS-ICL standalone against Laplace, on the same six regime axes as the site's standalone radar. Each radius is (wins + ½·ties) / n divided by one half, so an even split with Laplace sits on the dashed 1.0 ring; outward beats Laplace more often, inward less. Here a series counts as a win when the model's mean per-series log score exceeds Laplace's by any amount, and as a tie only at exact equality: the same rule the comparison radar uses, and a different one from the Diebold–Mariano win, draw and loss above, which fold statistically unresolved differences into draws. The two agree on direction and differ in how they treat small gaps. The solid polygon is the headline arm and the dashed grey one, where present, is the tight nine-decile reconstruction. The M4-hourly set splits into soft and hard waveforms by corpus order, matching that radar.

Collaborative use

The sandwich arms (+lap, ~lap, @lap, &lap) have not been run on TS-ICL. The sidecar wraps any per-step predictive, so they can be added without retraining. See the sidecar pattern.

Protocol

Fixed 128-length context, rolling one-step test window, no fitting, each model in its own environment. Strata split the cached FRED universe and the M4-hourly set by frequency and regime. Full method on the sidecar pattern page and in the methodology.
